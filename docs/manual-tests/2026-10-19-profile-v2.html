Jak sprawdzić

  1. Otwórz gałąź feat/profile-v2 na GitHubie — README renderuje się pod listą plików.
  2. Przełącz motyw GitHuba (Settings → Appearance) na jasny i ciemny: każda karta musi zmienić wersję, bez białych/czarnych prostokątów.
  3. Kliknij: nagłówek → romanczuk.online; Vector Digital → nowy mail z tematem „Audyt — Vector Digital”; Strummy, home-ops, romanczuk.online, instagram-stories-webhook → odpowiednie repo.
  4. Sprawdź „ń” w „Romańczuk” w nagłówku (był problem z czcionką, naprawiony).
  5. Telefon (aplikacja GitHub / wąskie okno): obrazy się skalują, karty home-ops i romanczuk.online stoją obok siebie, tekst czytelny po powiększeniu.
  6. Po merge do main: github.com/PiotrRomanczuk pokazuje nową wersję.
